## Hogyan használd?

Beállításhoz a telepítés, funkciók és adatkapcsolatok fejezetéből indulj.
Saját sablonhoz a témák, firmware-módosításhoz a fejlesztés fejezetet keresd.
A történeti tervek és átvételi listák megmaradtak, de elkülönülnek az aktuális
útmutatóktól; a kiadási leírások a verziótörténetben vannak.

A README-ből áthelyezett bővebb szövegek:
[részletes projektáttekintés](project-overview.md),
[első indítás](first-start.md), [fejlesztői ellenőrzés](developer-checks.md).
A képek a saját útmutatójuk mellett maradnak; a [téma-előnézetek](../README.md#téma-előnézetek)
továbbra is a főoldalon láthatók.

[Szerkesztési szabályok és az átrendezés tartalommegőrzése](documentation-structure.md).
