# Telepítés és használat

[Dokumentációs kezdőlap](../README.md) · [Projektáttekintés](../../README.md)

Első beüzemelés, hardver, SD-kártya és napi kezelés.

## Ajánlott olvasási sorrend

Új készüléknél az első indítás és az USB-telepítés után válassz adatkapcsolatot.
Már működő készüléknél a konfiguráció és a gesztusok leírása a kiindulópont.
A [mentés és frissítés](../maintenance/README.md) külön témakör.
