# Fejlesztési tervek és átadások

[Dokumentációs kezdőlap](../README.md) · [Projektáttekintés](../../README.md)

Dátumhoz vagy fejlesztési fázishoz kötött tervek, tapasztalatok és átvételi jegyzetek.

## A történeti anyagok szerepe

Az alábbi dokumentumok eredeti tartalmát, dátumait, ismert hibáit és korábbi
ellenőrzési eredményeit megőrizzük. Ezek fejlesztési fázisok lenyomatai:
a bennük szereplő „még nincs kész” vagy „még nem tesztelt” állapot nem
feltétlenül a jelenlegi kiadásra vonatkozik.

A használathoz a [funkciók útmutatóiból](../features/README.md), a kiadott
változatokhoz a [verziótörténetből](../versions/README.md) indulj.
A világítási fejlesztés készülékes visszaellenőrzése és korábbi hibájának
javítása az [eredeti világítási leírásban](../lighting-controller.md#készülékes-visszaellenőrzés--2026-11-13)
marad. A [memória- és teljesítménynapló](../performance.md) szintén őrzi a
korábbi készülékes tapasztalatokat.
