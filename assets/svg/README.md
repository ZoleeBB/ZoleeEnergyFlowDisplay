# SVG forrásgrafikák

Ez a könyvtár a firmware-be beágyazott dashboard-ikonok szerkeszthető SVG forrásait tartalmazza.

A grafikai készlet az elfogadott energia-dashboard látványterv vizuális világát követi: lágy, színes, részletes piktogramok; nem LVGL karakterikonok és nem futás közben összeállított primitív rajzok.

A firmware ugyanennek az assetkészletnek a beágyazott változatát használja a `main/app_assets.c` fájlból.
